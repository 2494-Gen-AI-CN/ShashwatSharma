# international space station (iss) tracker

this is a small python project i built to practice working with apis, json data, and python libraries.

the program gets information about astronauts in space and tracks the location of the international space station (iss) on a world map.

## features

- gets astronaut information using an api
- displays the iss location on a world map
- updates the iss position every 5 seconds
- shows latitude, longitude, altitude, and speed
- saves astronaut information in a text file

## technologies used

- python
- turtle graphics
- json
- urllib
- geocoder

## how to run

install the required library:

`python -m pip install geocoder`

run the program:

`python main.py`

make sure the images folder contains `map.gif` and `iss.gif`.
